# Decision: Abandon Transformer/LLM Paradigm

## Context

Project launch. Initial framing risked defaulting to transformer-based architectures
and next-token prediction as the foundation for AGI research.

## Decision

**Transformer architecture and LLM-based approaches are explicitly excluded as the
foundation.** We are redesigning intelligence from scratch.

## Directives

### DO NOT:
- Assume transformer = intelligence
- Use LLM as a base or reference architecture
- Default to next-token prediction as the learning mechanism
- Treat scaling existing approaches as the path to AGI

### DO:
- Research and design **new neural network architectures**
- Explore alternative learning mechanisms
- Design new memory, perception, and reasoning systems from first principles
- Build novel formulas and mathematical frameworks

## Approved Research Directions

Explore alternatives including (but not limited to):
- Recurrent architectures
- Sparse networks
- Modular/neural module systems
- State-based models
- Predictive coding frameworks
- Evolutionary approaches
- Hebbian learning mechanisms
- Other novel paradigms

## Implications

- All architecture docs from `definer` must start from scratch
- `researcher` should focus on non-transformer literature
- Coders should not use LLM APIs or transformer libraries as core components
- Evaluation benchmarks must measure intelligence, not language modeling
