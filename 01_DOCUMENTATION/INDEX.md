## Documentation Standards

- All documents use Markdown with YAML frontmatter
- Every factual claim must be cited with a source
- Cross-references use `[[wikilinks]]`
- Dates: YYYY-MM-DD format
- Decision records include: date, context, decision, rationale, consequences
